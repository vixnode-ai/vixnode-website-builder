# Industry Evidence Modules

Select by actual business and audience, not preferred colors. `Industry-*` is a discoverability link to the existing theme category, not a required palette. Use the profile ID in the generated specification. Apply only evidence relevant to the user's scope; do not invent missing facts.

## Manufacturing and Craft Overlay

ID: `manufacturing-craft`. No existing Industry theme is an exact manufacturing category; this overlay may accompany `home-interior`, `luxury-premium`, `automotive-transport` or stand alone when appropriate.

Audience: commissioners, procurement teams, designers and partners. Evidence: materials, production methods, actual equipment/capabilities, tolerances when supplied, case details, quality checks and inquiry requirements. Structure process content around what the buyer needs to understand, not an invented factory tour. Use real production imagery or clearly labeled explanatory diagrams. Do not invent certifications, capacity, minimum orders, tolerances or lead times.

## Extension Rule

For a mixed business choose a primary audience/task and add only the second profile's necessary evidence. For an unsupported industry define audience, evidence, terminology, constraints and integration dependencies in the output. Keep palette and style independent. Missing evidence remains a named content request, not filler testimonials or placeholder statistics presented as facts.
